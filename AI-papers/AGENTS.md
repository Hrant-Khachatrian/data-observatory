# AI Papers collection

Read [README.md](README.md) before adding a presentation. Maintain the public registry in `papers.json` and regenerate `index.html` with `python3 AI-papers/build.py` from the repository root. Preserve existing URLs and other contributors' entries.

All published content must contain only public links. Do not include internal dashboards, private hosts, local files, localhost, private IP addresses, personal filesystem paths, or unrequested unpublished experiment details. Include primary-source citations, distinguish illustrative examples from actual benchmark items, and state material source-access limitations.

Keep each presentation in its own stable folder and include a relative link to the collection. Verify slide count, browser layout, keyboard navigation, overview mode, and print layout. Keep QA and downloaded research materials outside the published tree.
