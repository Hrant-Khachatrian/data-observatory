SETTING · 02

Ground-level revisits, separated by years

The same place can look very different without a persistent structural change.

  • Moving cameras introduce viewpoint shifts and occlusion.
  • Lighting, weather, vehicles and vegetation can distract from infrastructure changes.
  • The target is a set of meaningful long-term differences.

This is street-view related work. It does not evaluate aerial imagery or SECOND.

MSLS is originally a visual place recognition dataset. Its source collection spans 30 cities across six continents. Spot-the-shift curates a smaller benchmark subset.

Pair selection uses capture points within 0.25 m, the same orientation category, and different image sequences.

Geographic proximity helps find revisits. It does not provide pixel-perfect registration.

TASK · 04

Describe each difference and identify its evidence

InputExpected output per difference
Two images of one revisited locationNatural-language description
Changes may be absent or multipleImage index: 1 or 2
No fixed land-cover class vocabularySpatial localization: point, box or mask

The general task supports different spatial representations. The experiments compare free-form captioning and captioning with explicit point coordinates.

The request asks for all relevant differences. It does not systematically vary a requested source-to-destination land-cover transition.

DISTRACTORS · 08

An unchanged pair should produce no change units

Some pairs contain no structural change of interest.

Weather, illumination and temporary objects can still differ visibly. Correct behavior is to abstain from inventing a structural change.

Here “no change” means an empty list of relevant changes. It does not mean segmenting all areas that stayed the same.

ANNOTATION · 09

Model proposals receive human verification

  1. Find revisits: MSLS location and orientation metadata select candidate pairs.
  2. Propose differences: Gemini 3 Flash supplies initial descriptions. Gemma structures them into change units.
  3. Verify: human annotators correct the semantic changes and draw boxes around relevant evidence.
  4. Produce masks: SAM 3 operates on the box crops to obtain spatial annotations.

Human verification matters, but the annotation pipeline still starts from a model’s candidate differences.

METRICS · 10

Atomic matching makes direction errors visible

Parse predicted and reference captions into units: object type + action.

StepEvaluation operation
Semantic similaritySentence-BERT cosine similarity between object types
Type-only score (T)Match semantically similar types
Type + action score (T+A)Allow a match only when the action also agrees
AssignmentHungarian matching, then discard similarity below 0.5
Count outcomesMatched units = TP; unmatched predictions = FP; missed units = FN

METRICS · 11

Abstention and localization need separate measures

MeasureMeaning
Precision / recall / F1Correct described change units versus hallucinated or missed units
TNRFraction of distractor pairs with no predicted change
HRAverage number of predicted change units per distractor pair
SRAverage soft localization score: 1 / (d + 1), with d in pixels to the nearest ground-truth mask point

A point inside the reference mask receives 1. Points outside it receive a distance-decaying score.

SR is a soft point score, despite the “success” label. It is not segmentation IoU. HR is a count per pair, not a bounded percentage.

SOURCES & LIMITS · 18

What this paper establishes

General VLMs struggle to describe and ground persistent changes in real street-view revisits. Explicit localization requests can change precision and recall.

  • The benchmark supports multiple and absent changes, with semantic and spatial annotations.
  • Its metrics and numbers cannot be compared directly with foreground mask IoU.
  • The fine-tuned model is separate from the generalist zero-shot baselines.
  • The street-view domain and structural-change definition limit transfer to aerial land-cover transitions.
