# Data Observatory

Random data reports by Hrant Khachatrian (and Codex).

## Published reports

- **NISAR S-band Coverage** — global released GCOV footprints and country counts, with reproducible metadata from October 10, 2026

- **Science Funding in Armenia** — Armenian charts of science budgets, competitive grants, the 2030 target, and YerevaNN funding

- **HESC Grant Awards Explorer** — searchable public grant-award records from 2020–2026
- **YSU Compute Usage Reports** — periodic scientific-computing utilization reports
- **NVIDIA GPUs by Country** — sortable 2027 deployment and pipeline audit with per-capita rankings and source evidence

The site is published with GitHub Pages at <https://hrant-khachatrian.github.io/data-observatory/>.

## Structure

- `nisar-sband/` — NISAR S-band GCOV coverage audit and metadata

- `science-funding/` — science budgets and research funding charts

- `hesc-grants/` — migrated from `Hrant-Khachatrian/HESC-grants`
- `compute-usage/` — migrated from `Hrant-Khachatrian/compute-usage-reports`
- `nvidia-gpus/` — global country-level NVIDIA GPU evidence audit
