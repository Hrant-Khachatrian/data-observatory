# Grant-result additions

The explorer includes its original September 13, 2026 audited dataset plus the
source-linked additions in this directory. Preserve these additions when
regenerating the page from the older Markdown appendix.

`2026-10-22.json` contains six integration and thirteen PostDoc awards, checked
November 17, 2026 against the Armenian and English HESC result tables. Each row
retains the official code, Armenian fields, original funding units, normalized
AMD amount, source URL and extraction note.

October 22 is the publication date of the result tables. It is not a verified
contract start date. The Armenian integration-results page is mistitled as
professional training; its six `26IRF` rows agree with the correctly titled
English integration-results page.

`2026-11-23.json` contains all 35 projects recommended for funding in the
2026 Remote Laboratories competition, checked November 24, 2026 against the
annex to ministerial order No. 2443-Ա/2. Each row preserves the group lead(s),
co-lead, Armenian title and host, requested amount, and a link to its PDF page.
The records use the date of the ministerial order. Contract start dates and
contracted amounts are not given in the annex.
